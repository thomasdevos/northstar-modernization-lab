# Review candidates

Claude Code may prepare synthetic, chapter-scoped candidate fixtures here. Candidate material is not an accepted golden master.

Promotion requires a named human to:

1. review provenance, normalization, coverage, and every unexplained difference;
2. record the candidate digest and approval;
3. copy the exact approved candidate into the protected `fixtures/golden-master/` tree outside the Claude Code session;
4. record the promoted digest and confirm that it matches the approved candidate digest.

Claude Code cannot write to, approve, or silently refresh the protected golden-master tree.
