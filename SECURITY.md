# Security policy

This repository is an educational lab containing synthetic data only.

## Reporting a vulnerability

Open a GitHub Security Advisory for vulnerabilities in the supplied code or controls. Do not open a public issue containing exploit details, credentials, confidential code, customer data, or production logs.

Include the affected revision, a minimal synthetic reproduction, the expected boundary, and the observed behavior. Security reports do not constitute approval to test systems outside this repository.

## Supported version

The latest tagged starting-state release is supported. Claude Code compatibility is additionally bounded by the version recorded in `compatibility/claude-code-2.1.170.json`.
